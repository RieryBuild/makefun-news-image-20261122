## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

`main.ts` (Node 22, stdlib only) validates the shipped `entry.png` — JPEG bytes, 1024×1024, whole file, at most 1 MiB — and copies it byte for byte to `$MAKEFUN_OUTPUT_DIR/entry.png`. Two runs write identical bytes. See `NEWS.md` for the full story list with dates and sources.
